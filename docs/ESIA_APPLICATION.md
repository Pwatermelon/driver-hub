## 2. Предмет заявки

Заявитель просит предоставить информационной системе **Driver Hub** доступ к ЕСИА для:

1. идентификации и аутентификации физических лиц — водителей;
2. получения персональных данных из подтверждённой учётной записи ЕСИА;
3. получения сведений о водительском удостоверении;
4. верификации профиля водителя в реестре Driver Hub.

Подключение требуется на **тестовом** и далее на **продуктивном** контуре ЕСИА.

---

## 3. Назначение информационной системы

**Driver Hub** — информационная система централизованного реестра водителей для логистических и транспортных компаний.

Система обеспечивает:

- создание и ведение профиля водителя (Hub ID);
- подтверждение личности водителя через Госуслуги;
- формирование досье для проверки при найме и допуске к перевозкам;
- обмен сведениями между организациями-пользователями в рамках целей системы.

Обработка персональных данных осуществляется на основании согласия субъекта персональных данных в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

## 4. Запрашиваемые scope ЕСИА

Заявитель запрашивает следующие права доступа (scope):

```
openid
fullname
birthdate
gender
snils
inn
mobile
email
id_doc
drivers_licence_doc
```

### Обоснование запроса scope

| Scope | Обоснование необходимости |
|---|---|
| `openid` | Идентификация субъекта персональных данных, получение стабильного идентификатора `oid` для привязки учётной записи водителя в ИС Driver Hub |
| `fullname` | Получение фамилии, имени, отчества для профиля водителя и досье |
| `birthdate` | Получение даты рождения как обязательного идентификационного признака |
| `gender` | Получение сведений о поле для полноты профиля |
| `snils` | Получение СНИЛС для однозначной идентификации водителя |
| `inn` | Получение ИНН для дополнительной идентификации |
| `mobile` | Получение номера мобильного телефона для связи и уведомлений |
| `email` | Получение адреса электронной почты из учётной записи ЕСИА |
| `id_doc` | Получение сведений паспорта РФ для усиленной проверки личности |
| `drivers_licence_doc` | Получение сведений водительского удостоверения: серия, номер, категории, даты выдачи и окончания действия, орган выдачи |

## 5. Состав данных, получаемых и обрабатываемых ИС

### 5.1. Данные профиля ЕСИА

- идентификатор учётной записи в ЕСИА (`oid`);
- фамилия, имя, отчество;
- дата рождения;
- пол;
- СНИЛС;
- ИНН;
- номер мобильного телефона;
- адрес электронной почты;
- признак подтверждённой учётной записи.

### 5.2. Данные водительского удостоверения

- серия водительского удостоверения;
- номер водительского удостоверения;
- дата выдачи;
- дата окончания срока действия;
- категории транспортных средств;
- наименование органа, выдавшего удостоверение.

### 5.3. Данные паспорта гражданина РФ

- серия и номер паспорта;
- дата выдачи;
- наименование органа, выдавшего паспорт.

### 5.4. Дополнительно запрашивается возможность подключения документов Цифрового профиля гражданина

В рамках дальнейшего развития интеграции заявитель запрашивает доступ к следующим типам сведений / документов:

- `RF_DRIVING_LICENSE` — водительское удостоверение в цифровом профиле;
- `GIBDD_DRIVER_LICENSE` — сведения о водительском удостоверении из ГИБДД.

## 6. Сценарий использования данных

1. Водитель регистрируется в ИС Driver Hub и получает публичный идентификатор Hub ID.
2. Водитель инициирует подтверждение личности через Госуслуги в личном кабинете ИС.
3. Водитель проходит авторизацию в ЕСИА и предоставляет согласие на передачу данных ИС Driver Hub.
4. ИС Driver Hub получает authorization code, обменивает его на access token и запрашивает сведения профиля и документов.
5. Полученные данные сохраняются в профиле водителя; устанавливается статус верификации.
6. Авторизованные организации-пользователи ИС используют Hub ID / QR-код водителя для просмотра досье в целях проверки при найме и организации перевозок.

Компании-пользователи не получают самостоятельного доступа к ЕСИА. Персональные данные не передаются третьим лицам вне контура ИС Driver Hub без правовых оснований.

## 7. Технические параметры подключения

| Параметр | Значение |
|---|---|
| Протокол | OAuth 2.0 / OpenID Connect ЕСИА |
| Тестовый контур ЕСИА | `https://esia-portal1.test.gosuslugi.ru` |
| Продуктивный контур ЕСИА | `https://esia.gosuslugi.ru` |
| Redirect URI (тест) | `https://________________/api/v1/auth/esia/callback` |
| Redirect URI (прод) | `https://________________/api/v1/auth/esia/callback` |
| Response type | `code` |
| Access type | `offline` |
| Подпись запросов | ГОСТ Р 34.10-2012 |
| Требование к учётной записи пользователя | только подтверждённая учётная запись ЕСИА |

Эндпоинты ИС Driver Hub:

- начало авторизации: `GET /api/v1/auth/esia/start`
- возврат из ЕСИА: `GET /api/v1/auth/esia/callback`

## 8. Меры по защите персональных данных

Заявитель обеспечивает:

- хранение и обработку персональных данных в защищённом контуре ИС;
- передачу данных исключительно по защищённым каналам связи (HTTPS);
- разграничение доступа по ролям (водитель / организация);
- журналирование операций верификации и доступа к досье;
- наличие политики обработки персональных данных и форм согласия субъекта;
- принцип минимизации: запрашиваются только scope, необходимые для верификации личности и водительского удостоверения.

## 9. Просительная часть

На основании изложенного просим:

1. Зарегистрировать (согласовать) информационную систему **Driver Hub** в ЕСИА.
2. Предоставить ИС Driver Hub доступ к scope, указанным в разделе 4 настоящей заявки, на **тестовом** контуре ЕСИА.
3. По результатам успешных испытаний предоставить доступ на **продуктивном** контуре ЕСИА.
4. Согласовать порядок подключения документов Цифрового профиля гражданина: `RF_DRIVING_LICENSE`, `GIBDD_DRIVER_LICENSE`.
