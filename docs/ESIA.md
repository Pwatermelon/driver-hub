# Интеграция с Госуслугами (ЕСИА / Цифровой профиль)

Документ описывает, что нужно для **реальной** верификации водителя и актуализации данных ВУ в Driver Hub.

## Что даёт ЕСИА для Driver Hub

| Задача | Механизм | Scope / документ |
|---|---|---|
| Вход и подтверждение личности | OAuth 2.0 / OpenID Connect ЕСИА | `openid` |
| ФИО, дата рождения, пол | REST `/rs/prns/{oid}` | `fullname`, `birthdate`, `gender` |
| СНИЛС / ИНН | REST профиля | `snils`, `inn` |
| Контакты | contacts embed | `mobile`, `email` |
| Паспорт | documents | `id_doc` |
| Водительское удостоверение | documents | `drivers_licence_doc` |
| Сведения ВУ из ГИБДД | Цифровой профиль / СМЭВ | `GIBDD_DRIVER_LICENSE` / `RF_DRIVING_LICENSE` |

В mock-режиме (`ESIA_MODE=mock`) всё это эмулируется без сертификатов.

## Пошаговое подключение (боевой контур)

### 1. Юридическая подготовка
1. Юрлицо с подтверждённой УЗ в ЕСИА.
2. КЭП руководителя / уполномоченного лица.
3. НПА / договорная база, обосновывающая обработку ПДн (152-ФЗ) и цель запроса согласий.
4. Для судимостей, медосмотров, лишений прав — **отдельные виды сведений СМЭВ** и отдельные правовые основания. Их нельзя получить «просто так» через обычный OAuth ЕСИА.

### 2. Регистрация ИС
1. Зарегистрировать информационную систему в **СМЭВ** (получить мнемонику).
2. На [технологическом портале ЕСИА](https://esia.gosuslugi.ru/console/tech) создать ИС с **той же мнемоникой**.
3. Указать `redirect_uri` (у нас: `/api/v1/auth/esia/callback`).
4. Загрузить сертификат ИС (для продуктивной ЕСИА обычно **ГОСТ Р 34.10-2012**).

### 3. Заявки на доступ
1. Тестовая среда → заявка на `sd@sc.digital.gov.ru` (форма из регламента).
2. В заявке перечислить scope (см. таблицу выше).
3. После успешных тестов — заявка в продуктив.

Актуальная инструкция: [Как подключиться к ЕСИА](https://info.gosuslugi.ru/articles/Как_подключиться_к_ЕСИА/).

### 4. Технический поток (уже реализован в коде)

```
Водитель → GET /api/v1/auth/esia/start
         → редирект на ЕСИА (/aas/oauth2/ac)
         → согласие пользователя
         → callback ?code&state
         → обмен code на access_token (/aas/oauth2/te)
         → GET /rs/prns/{oid}?embed=(contacts.elements,documents.elements)
         → обновление профиля + ВУ в Driver Hub
```

Клиент: `internal/esia/live.go` (каркас live) и `internal/esia/mock.go` (демо).

### 5. Подпись запросов
Официальная ЕСИА требует подпись `client_secret` по ГОСТ. Для этого обычно используют:
- КриптоПро / ГОСТ-engine в OpenSSL;
- либо коммерческий **ЕСИА-шлюз** (проксирует подпись и токены).

В `LiveClient` сейчас реализована RSA-подпись как заглушка для стендов/шлюзов с RS256. Перед продом замените `sign()` на ГОСТ.

## Данные, которые НЕ приходят «из коробки» через ЕСИА

| Данные | Как получать | Комментарий |
|---|---|---|
| Лишение прав / ограничения ВУ | СМЭВ ↔ ГИБДД / ФИС ГИБДД-М | В модели: `license_suspensions` |
| Штрафы ГИБДД | СМЭВ / открытые API ГИБДД (ограниченно) | В модели: `fines` + source=`gibdd` |
| Справка о судимости | СМЭВ ↔ МВД (строгие основания) | В модели: `criminal_records` |
| Медсправка (форма 003-В/у и аналоги) | Загрузка водителем / СМЭВ при наличии ВС | В модели: `medical_certificates` |
| Рекомендации / жалобы / блэклист / ДТП от компаний | Только внутри Driver Hub | Это бизнес-данные платформы |

## Согласия и доступ компаний

Driver Hub **не** должен отдавать ПДн любой компании по Hub ID.

Реализованная модель:
1. Публичная карточка (`/drivers/{hubID}/public`) — маска ФИО + агрегаты.
2. Полное досье (`/drivers/{hubID}/dossier`) — только при активном `access_grant` от водителя.
3. Водитель выдаёт/отзывает доступ: `POST/DELETE /me/grants`.

Для ЦПГ дополнительно нужно согласие гражданина через платформу согласий (`permissions`, `purposes`, `sysname`, `actions`).

## Переменные окружения

```env
ESIA_MODE=live
ESIA_BASE_URL=https://esia-portal1.test.gosuslugi.ru   # тест
# ESIA_BASE_URL=https://esia.gosuslugi.ru               # прод
ESIA_CLIENT_ID=...
ESIA_CLIENT_SECRET=...
ESIA_REDIRECT_URI=https://your.domain/api/v1/auth/esia/callback
ESIA_SCOPES=openid,fullname,birthdate,gender,snils,inn,mobile,email,id_doc,drivers_licence_doc
ESIA_KEY_PATH=/certs/isia.key
ESIA_CERT_PATH=/certs/isia.cer
```

## Checklist перед продом

- [ ] ИС зарегистрирована в СМЭВ и ЕСИА
- [ ] Scope согласованы заявкой
- [ ] ГОСТ-подпись запросов
- [ ] HTTPS + корректный redirect_uri
- [ ] Только подтверждённые УЗ (`trusted`)
- [ ] Политика ПДн, согласия, аудит доступа
- [ ] Отдельные контуры для МВД/медицины/ГИБДД при необходимости
